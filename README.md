# shop

Tiny order-pricing library used to try out automated PR review.

```bash
python -m unittest discover -s tests -t .
```

## Promotions

- Bulk discounts: 5% from 10 units, 10% from 20 units, 15% from 50 units.
- Coupons: an extra percentage off the discounted total.
- `shop.report`: per-customer spend and CSV export.
